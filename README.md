# CampusConnect

CampusConnect is a centralized student platform designed to bring important campus information into one place.

It helps students access announcements, study resources, events, opportunities, questions, and lost & found information through a simple web-based dashboard.

## Features

- Student login and registration
- Student dashboard
- Campus announcements
- Study resources and notes
- Events and event registration
- Internship and other opportunities
- Student questions and discussions
- Lost & Found section
- Global search
- Notifications
- Student profile
- Campus statistics
- Bookmarks

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub
